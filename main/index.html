    Full installation guide
    Install ASH
    # Install in an isolated environment.
    $pipx install git+https://github.com/awslabs/automated-security-helper.git@v3.7.0
    # Run without a permanent install. Requires uv.
    $uvx --from git+https://github.com/awslabs/automated-security-helper.git@v3.7.0 ash --help
    # Install in your active Python environment.
    $pip install git+https://github.com/awslabs/automated-security-helper.git@v3.7.0
    # From your project directory
    $ash --mode container

    Run enabled scanners in an isolated container. Requires an OCI-compatible runtime.

    FAQ

    All questions
    Do I need an AWS account?

    No. Core ASH scanning runs locally or in a container. An AWS account is needed only for optional integrations with services such as Security Hub or S3.

    Which scan mode should I use?

    Use container for a consistent environment with all scanner dependencies, local for your development machine, and precommit for a faster subset before commits. Compare execution modes.

    Can I customize the rules and reports?

    Set scanners, thresholds, ignore paths, and suppressions in .ash.yaml. Configuration reference.

    Does ASH replace a security review?

    No. Coverage depends on enabled scanners, language, file type, and configuration.
