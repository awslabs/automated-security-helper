    Environment variables¶

    This page is generated from the code that reads each variable by scripts/generate_env_var_reference.py. Edits made to this file by hand are overwritten the next time it is generated.

    ASH reads 141 environment variables: 58 of its own (ASH_ prefix) and 83 set by other tools or the platform. The tables list every place each one is read. A variable that sets a CLI option links to that option; the option on the command line takes precedence over the variable.

    Columns:

    • Default: the value the code uses when the variable is unset, as written in the code, at each read that supplies one. Where none does, or the only one is an empty string, it is the default of the CLI option the variable sets, or of the configuration key it is the default of. Blank means none of these supplies one (the code checks whether the variable is set, or treats unset as empty).
    • Container image: the value the ASH container image sets, from an ENV line in the Dockerfile, and the build stage that sets it.
    • Read at: the file of each read and the function, method or script function it is in, or module level or top level when it is in none. ash and utils/ are the shell and PowerShell entry scripts; everything else is the Python package.
    • Purpose: the option's help text, or the code comment or docstring at the read, quoted with the file and function it is in. "Purpose not documented in code." means the code around the read does not say.

    Variables a configuration file can read¶

    A value in a configuration file that begins with ${NAME} or ${NAME:default} has the reference replaced by that environment variable. Only names that start with ASH_ and these names are substituted: AWS_DEFAULT_REGION, AWS_PROFILE, AWS_REGION. Any other reference is left as written, with a warning. The prefix and the list are defined in automated_security_helper/core/constants.py.

    Lookups that could not be resolved¶

    These reads take the variable name from a value the generator cannot resolve without running ASH: a name read from a configuration file, built at run time, or passed in from somewhere it cannot follow. A variable read only through one of these sites is not in the tables above.
