
 Usage: ashx config update [OPTIONS] [config_path]

 Update an existing configuration file with the specified modifications.

 This command applies changes to an ASH configuration file using the same syntax as
 --config-overrides.

┌─ Arguments ─────────────────────────────────────────────────────────────────────────────────────┐
│   config_path      <str>  The path to the configuration file to update. By default, ASH looks   │
│                           for the following config file names in the source directory of a      │
│                           scan: ['.ash.yml', '.ash.yaml', '.ash.json', 'ash.yml', 'ash.yaml',   │
│                           'ash.json'] (each at the root, then in .ash/), then ['.ashrc.toml',   │
│                           '.ashrc.yaml', '.ashrc.yml', '.ashrc.json', 'ashrc.toml',             │
│                           'ashrc.yaml', 'ashrc.yml', 'ashrc.json'] at the root, then the        │
│                           tool.ash table of pyproject.toml at the root; the first found is      │
│                           used.                                                                 │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐
│ --set                            <str>  Configuration modifications specified as key-value      │
│                                         pairs (e.g., 'global_settings.severity_threshold=LOW'). │
│                                         Supports lists with , append mode with key+=, and JSON  │
│                                         syntax.                                                 │
│ --verbose      --no-verbose             Enable verbose logging [default: no-verbose]            │
│ --debug        --no-debug               Enable debug logging [default: no-debug]                │
│ --color        --no-color    -C         Enable/disable colorized output [default: color]        │
│ --dry-run      --no-dry-run             Show changes without writing to file                    │
│                                         [default: no-dry-run]                                   │
│ --help     -h                           Show this message and exit.                             │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
