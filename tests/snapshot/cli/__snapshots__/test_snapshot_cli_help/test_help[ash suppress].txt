
 Usage: ash suppress [OPTIONS] COMMAND [ARGS]...

 Create symbol suppressions and keep their content-hash lock (.ash.lock) current.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ add      Add a symbol suppression and lock its file's content hash.                              │
│ refresh  Record a new review: re-hash locked files whose bytes changed.                          │
│ verify   Check the lock against the tree. Exits 1 when anything is out of date.                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
