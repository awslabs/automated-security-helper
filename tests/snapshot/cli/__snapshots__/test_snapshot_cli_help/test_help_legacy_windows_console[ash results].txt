
 Usage: ash results [OPTIONS] COMMAND [ARGS]...

 Read, compare and combine the results of saved ASH scans: report, diff, trend, merge and inspect.
 None of them runs a scan.

┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐
│ --help          Show this message and exit.                                                     │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Commands ──────────────────────────────────────────────────────────────────────────────────────┐
│ report   Generate a report from ASH scan results using the specified reporter plugin.           │
│ diff     Compare the findings in two saved ASH scans without running a scan.                    │
│ trend    Show new, carried and fixed findings over a series of saved ASH scans.                 │
│ merge    Merges the results of a sharded scan into one unified report.                          │
│ inspect  Inspect and analyze ASH outputs and reports                                            │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
