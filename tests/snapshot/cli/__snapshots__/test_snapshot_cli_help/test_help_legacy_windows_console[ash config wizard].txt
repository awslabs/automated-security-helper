
 Usage: ash config wizard [OPTIONS]

 Interactive configuration wizard.

 Reads an existing .ash.yaml (if present), walks through scanner,
 reporter, offline-mode, and community-plugin settings interactively,
 then writes the result back.

┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐
│ --config   -c                <str>  Path to read/write the configuration file.                  │
│                                     [env var: ASH_CONFIG]                                       │
│                                     [default: .ash/.ash.yaml]                                   │
│ --verbose  -v                       Enable verbose logging                                      │
│ --debug    -d                       Enable debug logging                                        │
│ --color        --no-color           Enable/disable colorized output [default: color]            │
│ --help                              Show this message and exit.                                 │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
