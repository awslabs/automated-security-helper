
 Usage: ash scan [OPTIONS] COMMAND [ARGS]...

 Scan code, infrastructure, secrets, and dependencies.

 Name what to scan: `ash scan fs <path>` scans a directory. `ash scan` with no subject still scans
 the working directory, but that form is deprecated and will be removed in ASH v4.0.

│ --help          Show this message and exit.                                                     │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Commands ──────────────────────────────────────────────────────────────────────────────────────┐
│ fs  Scan a directory for code, infrastructure, secrets, and dependency findings.                │
