
 Usage: ash inspect findings [OPTIONS]

 The `inspect findings` command provides an interactive TUI to explore the findings and identify
 actions to quickly take.

 A finding's code is the code snippet the results hold, wherever the results file is.
 For a finding with none, its lines are read from its file only when the results
 file sits in <root>/.ash/ash_output, and only from a regular file inside <root>
 (a hard link inside the tree counts as a file in it, as it does for the scanners);
 otherwise the detail view says "(source not shown)".

┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐
│ --output-dir           <path>  Path to the output directory containing an ASH Aggregated        │
│                                Results JSON report file to analyze.                             │
│ --report-file          <str>   Name of the report file to analyze. Defaults to                  │
│                                'ash_aggregated_results.json'.                                   │
│                                [default: ash_aggregated_results.json]                           │
│ --config       -c      <path>  Path to the configuration file where suppressions should be      │
│                                saved. By default, ASH searches for ['.ash.yml', '.ash.yaml',    │
│                                '.ash.json', 'ash.yml', 'ash.yaml', 'ash.json'] (each at the     │
│                                root, then in .ash/), then ['.ashrc.toml', '.ashrc.yaml',        │
│                                '.ashrc.yml', '.ashrc.json', 'ashrc.toml', 'ashrc.yaml',         │
│                                'ashrc.yml', 'ashrc.json'] at the root, then the tool.ash table  │
│                                of pyproject.toml at the root; the first found is used in the    │
│                                scanned directory (the one holding the results'                  │
│                                .ash/ash_output), or in the current directory when the results   │
│                                sit elsewhere. With none found, suppressions go to a new         │
│                                .ashrc.yaml there.                                               │
│                                [env var: ASH_CONFIG]                                            │
│ --help                         Show this message and exit.                                      │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
