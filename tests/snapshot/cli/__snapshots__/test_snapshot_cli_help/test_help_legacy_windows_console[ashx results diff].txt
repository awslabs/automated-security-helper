
 Usage: ashx results diff [OPTIONS] {before} {after}

 Compare the findings in two saved ASH scans without running a scan.

│ *    before      <path>  Baseline ASH scan results JSON file. [required]                        │

└─────────────────────────────────────────────────────────────────────────────────────────────────┘

│ --help    -h                   Show this message and exit.                                      │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
