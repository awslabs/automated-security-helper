│                                    uses indices 0, 1 and 2. Each shard runs a disjoint subset   │
│                                    of the scanners and records which ones in its results;       │
│                                    recombine them with 'ash merge'.                             │
│                                    [env var: ASH_SHARD_INDEX]                                   │
