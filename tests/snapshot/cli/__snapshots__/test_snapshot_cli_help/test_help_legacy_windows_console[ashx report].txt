
 Usage: ashx report [OPTIONS]

 Generate a report from ASH scan results using the specified reporter plugin.

┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐
│ --format                                <str>                       Report format to generate   │
│                                                                     (reporter plugin name).     │
│                                                                     Defaults to 'markdown'.     │
│                                                                     Examples values:            │
│                                                                     aggregated, text,           │
│                                                                     flat-json, yaml, csv, html, │
│                                                                     dict, junitxml, markdown,   │
│                                                                     sarif, asff, ocsf,          │
│                                                                     cyclonedx, spdx, custom     │
│                                                                     [default: markdown]         │
│ --output-dir                            <str>                       The directory to output     │
│                                                                     results to                  │
│                                                                     [env var: ASH_OUTPUT_DIR]   │
│ --log-level                             <QUIET|SIMPLE|ERROR|INFO|V  Set the log level.          │
│                                         ERBOSE|DEBUG|TRACE>         [default: INFO]             │
│ --config            -c                  <str>                       The path to the             │
│                                                                     configuration file. By      │
│                                                                     default, ASH looks for the  │
│                                                                     following config file names │
│                                                                     in the source directory of  │
│                                                                     a scan: ['.ash.yml',        │
│                                                                     '.ash.yaml', '.ash.json',   │
│                                                                     'ash.yml', 'ash.yaml',      │
│                                                                     'ash.json'] (each at the    │
│                                                                     root, then in .ash/), then  │
│                                                                     ['.ashrc.toml',             │
│                                                                     '.ashrc.yaml',              │
│                                                                     '.ashrc.yml',               │
│                                                                     '.ashrc.json',              │
│                                                                     'ashrc.toml', 'ashrc.yaml', │
│                                                                     'ashrc.yml', 'ashrc.json']  │
│                                                                     at the root, then the       │
│                                                                     tool.ash table of           │
│                                                                     pyproject.toml at the root; │
│                                                                     the first found is used.    │
│                                                                     Alternatively, the full     │
│                                                                     path to a config file can   │
│                                                                     be provided by setting the  │
│                                                                     ASH_CONFIG environment      │
│                                                                     variable before running     │
│                                                                     ASH.                        │
│                                                                     [env var: ASH_CONFIG]       │
│ --config-overrides                      <str>                       Configuration overrides     │
│                                                                     specified as key-value      │
│                                                                     pairs (e.g.,                │
│                                                                     'reporters.cloudwatch-logs… │
│ --verbose           -v                                              Enable verbose logging      │
│ --debug             -d                                              Enable debug logging        │
│ --color                 --no-color  -C                              Enable/disable colorized    │
│                                                                     output                      │
│                                                                     [default: color]            │
│ --help              -h                                              Show this message and exit. │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
