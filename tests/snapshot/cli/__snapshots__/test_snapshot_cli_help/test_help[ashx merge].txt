
 Usage: ashx merge [OPTIONS]

 Merges the results of a sharded scan into one unified report.

 Pass one --results per shard. The command refuses to merge a set of shards that does not
 reconstruct exactly one whole scan, and its exit code is the verdict for the union — a shard that
 owned no failing scanner exits 0, so CI must gate on this command rather than on per-shard
 success.
