
 Usage: ash config update [OPTIONS] [config_path]

 Update an existing configuration file with the specified modifications.

 This command applies changes to an ASH configuration file using the same syntax as
 --config-overrides.

 Nothing is written, and the command exits 3, when the file is not a valid
 configuration, a --set cannot be applied, or the file changed while the
 command read it. A file that uses extends or patch, or reads the environment
 (${VAR} or !ENV references), or a TOML file, is refused with exit 1:
 rewriting it would lose what those express.

┌─ Arguments ─────────────────────────────────────────────────────────────────────────────────────┐
│   config_path      <str>  The configuration file, as a positional argument. Same as --config,   │
│                           which is preferred; when both are given they must name the same file. │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────────────────────────┐

│                                          config a scan of the current directory would use:      │
│                                          ['.ash.yml', '.ash.yaml', '.ash.json', 'ash.yml',      │
│                                          'ash.yaml', 'ash.json'] (each at the root, then in     │
│                                          .ash/), then ['.ashrc.toml', '.ashrc.yaml',            │
│                                          '.ashrc.yml', '.ashrc.json', 'ashrc.toml',             │
│                                          'ashrc.yaml', 'ashrc.yml', 'ashrc.json'] at the root,  │
│                                          then the tool.ash table of pyproject.toml at the root; │
│                                          the first found is used.                               │
│                                          [env var: ASH_CONFIG]                                  │
│ --set                             <str>  Configuration modifications specified as key-value     │
│                                          pairs (e.g.,                                           │
│                                          'global_settings.severity_threshold=LOW'). Supports    │
│                                          lists with , append mode with key+=, and JSON syntax.  │
