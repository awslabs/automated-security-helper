
 Usage: ash config wizard [OPTIONS]

 Interactive configuration wizard.

 Reads the existing config (the one a scan of the current directory would
 use, or --config), walks through scanner, reporter, offline-mode, and
 community-plugin settings interactively, then writes the result back.
 With no config yet, it creates .ashrc.yaml.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --config   -c                <str>  Path to read/write the configuration file. By default, the   │
│                                     config a scan of the current directory would use, or a new   │
│                                     .ashrc.yaml when there is none.                              │
│                                     [env var: ASH_CONFIG]                                        │
│ --verbose  -v                       Enable verbose logging                                       │
│ --debug    -d                       Enable debug logging                                         │
│ --color        --no-color           Enable/disable colorized output [default: color]             │
│ --help                              Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
