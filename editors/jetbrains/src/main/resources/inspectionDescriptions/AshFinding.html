Reports findings from the most recent Automated Security Helper (ASH) scan of this project.

Findings are not produced by this inspection. They come from running Tools → Run ASH Security Scan, which invokes the ASH CLI you have installed and reads the SARIF report it writes. Until a scan has been run, this inspection reports nothing.

The severity shown for each finding is the SARIF level from the report: error is shown as an error, warning as a warning and note as a weak warning. Where a result omits its own level, the level is taken from the rule's defaultConfiguration, and the tooltip says so.
