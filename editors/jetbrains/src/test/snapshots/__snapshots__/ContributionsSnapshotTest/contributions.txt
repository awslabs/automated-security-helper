plugin
  id: io.github.awslabs.ash
  name: ASH - Automated Security Helper
  vendor: Amazon Web Services <https://github.com/awslabs/automated-security-helper>
  since-build: 252
  until-build: null
  depends: [com.intellij.modules.platform]
  description:
    Runs the <a href="https://github.com/awslabs/automated-security-helper">Automated
        Security Helper</a> (ASH) command line tool over the open project and shows the findings
        inline, at the file and line the scanner reported.
        <br/><br/>
        This plugin contains no scanners and no copy of ASH. It invokes the <code>ashx</code>
        command on your PATH, falls back to <code>ash</code> when <code>ashx</code> is not
        installed, or runs the executable set in <b>Settings | Tools | ASH</b>, and reads the
        SARIF report ASH writes.
        <br/><br/>
        <b>Usage:</b> <i>Tools | Run ASH Security Scan</i>. Findings appear as editor errors and
        warnings, with severity taken from the SARIF report. A scan ASH reports as incomplete
        still shows the findings it produced, and says which scanners did not run.

  description page:
    <html>
    <body>
    Reports findings from the most recent Automated Security Helper (ASH) scan of this
    project.
    <p>
    Findings are not produced by this inspection. They come from running
    <i>Tools &rarr; Run ASH Security Scan</i>, which invokes the ASH CLI you
    have installed and reads the SARIF report it writes. Until a scan has been run, this
    inspection reports nothing.
    </p>
    <p>

    <code>error</code> is shown as an error, <code>warning</code> as a warning and
    <code>note</code> as a weak warning. Where a result omits its own level, the level is
    taken from the rule's <code>defaultConfiguration</code>, and the tooltip says so.
    </p>
