# The e2e tests a run must report as PASSED, one pytest node id per line.
#
# The e2e step in .github/workflows/ash-kubernetes-operator.yml runs
# `python -m tests.e2e.require_nodes e2e.log` after the suite, and fails unless the log
# has an exact `PASSED <node id>` line for every id here. Without it, deleting or
# renaming a test leaves a green run that no longer tests what it did.
#
# Every test marked @pytest.mark.negative_control must be listed, and every id listed
# must still be collected: tests/test_e2e_required_nodes.py checks both in the unit job,
# with no cluster. Remove an id only together with the test it names, on purpose.
