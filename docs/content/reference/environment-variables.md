## Variables a configuration file can read

A configuration file can substitute an environment variable into a value with `${NAME}` or `${NAME:default}`. Only names that start with `ASH_` and these names are substituted: `AWS_DEFAULT_REGION`, `AWS_PROFILE`, `AWS_REGION`. Any other reference is left as written. The rule is `ASH_CONFIG_ENV_VAR_PREFIX` and `ASH_CONFIG_ENV_VAR_ALLOWLIST` in `automated_security_helper/core/constants.py`.

## Lookups that could not be resolved

These reads take the variable name from a value the generator cannot resolve without running ASH: a name read from a configuration file, built at run time, or passed in from somewhere it cannot follow. A variable read only through one of these sites is not in the tables above.
