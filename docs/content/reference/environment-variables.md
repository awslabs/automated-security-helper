## Variables a configuration file can read

A value in a configuration file that begins with `${NAME}` or `${NAME:default}` has the reference replaced by that environment variable. Only names that start with `ASH_` and these names are substituted: `AWS_DEFAULT_REGION`, `AWS_PROFILE`, `AWS_REGION`. Any other reference is left as written, with a warning. The prefix and the list are defined in `automated_security_helper/core/constants.py`.
